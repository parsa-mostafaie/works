📖 راه‌اندازی همگام‌سازی

این ۵ مرحله را یک‌بار برای هر حساب GitHub انجام دهید. سپس همه دستگاه‌ها داده‌ی یکسان خواهند داشت.

۱

ساخت توکن دسترسی شخصی

فقط دسترسی gist لازم است. رایگان و حدود ۳۰ ثانیه طول می‌کشد.

باز کردن صفحه ساخت توکن در GitHub ↗
۲

کپی کردن توکن

شبیه این است: ghp_xxxxxxxxxxxxxxxxxxxx — مثل رمز عبور از آن محافظت کنید.

۳

ساخت Gist مخفی

نام فایل را works.json بگذارید و محتوای آن را [] (آرایه خالی) قرار دهید. روی Create secret gist کلیک کنید.

باز کردن GitHub Gist ↗
۴

کپی کردن شناسه Gist

از آدرس Gist: gist.github.com/USER/GIST-ID

می‌توانید کل آدرس را در برنامه جای‌گذاری کنید — شناسه به‌طور خودکار استخراج می‌شود.

۵

جای‌گذاری و آزمایش

به تنظیمات برگردید: شناسه Gist و توکن را جای‌گذاری کنید، سپس روی آزمایش اتصال بزنید. اگر موفق بود، همگام‌سازی الان را بزنید. تمام.

💡 نکته امنیتی: Gist «مخفی» در نتایج جستجو نمایش داده نمی‌شود، اما هرکس آدرس را داشته باشد می‌تواند آن را ببیند. رمز یا اطلاعات حساس در کارها قرار ندهید.
