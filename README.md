# کارها

مدیریت کارها با **استایل شیشه‌ای مدرن (Glassmorphism)**، **آیکون‌های SVG** و **تاریخ شمسی** — فارسی‌محور، RTL، با همگام‌سازی اختیاری از طریق GitHub Gist.

## ✨ ویژگی‌های نسخه جدید

- 🎨 **طراحی Glassmorphism** — پس‌زمینه گرادیانی با گرادیان‌های شناور و پنل‌های شفاف با blur
- 🎯 **آیکون‌های SVG** — بدون ایموجی، همه‌چیز با آیکون‌های feather-style
- 📅 **اولویت‌بندی هوشمند** — کارهای گذشته (حتی تیک‌نخورده) پایین‌تر نمایش داده می‌شوند
- 🕐 **چهار سطح اولویت** — فعال + آینده، فعال + گذشته، انجام‌شده
- 📱 **RTL کامل** — تمام رابط کاربری راست‌به‌چپ
- 🔗 **پیوندهای چندگانه** — هر کار می‌تواند چند لینک داشته باشد
- ☁️ **همگام‌سازی GitHub Gist** — بدون فیلترشکن
- 💾 **ذخیره‌سازی محلی** + همگام‌سازی بین تب‌ها

## 🚀 نصب و اجرا

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## 📊 منطق اولویت‌بندی

کارها بر اساس سه رتبه اولویت‌بندی می‌شوند:

| رتبه | شرط | رنگ چیپ تاریخ |
|------|------|---------------|
| **۰** | فعال + تاریخ امروز یا آینده | زرد/نارنجی (معمولی) |
| **۱** | فعال + تاریخ گذشته | 🔴 قرمز |
| **۲** | انجام‌شده (هر تاریخی) | خاکستری کم‌رنگ |

در هر رتبه، مرتب‌سازی انتخابی کاربر (تاریخ، آخرین ویرایش، الفبا) اعمال می‌شود.

## 🎨 Glassmorphism

- پس‌زمینه گرادیانی سه‌رنگ با سه orb متحرک
- پنل‌ها با `backdrop-filter: blur(20px) saturate(180%)`
- حاشیه‌های شفاف و سایه‌های نرم
- کارت‌های شیشه‌ای با hover animation

## 🎯 آیکون‌ها

تمام آیکون‌ها به‌صورت inline SVG در `js/utils.js` تعریف شده‌اند:

```js
Utils.iconSvg('calendar', 16)  // برمی‌گرداند: '<svg>…</svg>'
```

در HTML از `data-icon="name"` استفاده می‌شود و در `DOMContentLoaded` به‌طور خودکار تزریق می‌شود.

آیکون‌های موجود: `plus`, `x`, `check`, `undo`, `trash`, `edit`, `save`, `import`, `export`, `cloud`, `refresh`, `settings`, `search`, `tag`, `hash`, `calendar`, `link`, `filter`, `sort`, `chart`, `layers`, `inbox`, `book`, `external`, `plug`, `alert`, `shield`, `database`, `clock`, `flag`, `info`
