🔑 GitHub Gist Sync Setup

Follow these 5 steps once per GitHub account. Every device will then share the same data.

1

Create a personal access token

Only the gist scope is needed. It's free and takes ~30 seconds.

Open GitHub token page →
2

Copy the token

It looks like ghp_xxxxxxxxxxxxxxxxxxxx. Treat it like a password.

3

Create a secret gist

Name the file works.json and set content to [] (empty array). Click Create secret gist.

Open GitHub Gist →
4

Copy the Gist ID

From the gist URL: gist.github.com/YOUR-USER/GIST-ID

You can also paste the whole URL into the app — we'll extract the ID automatically.

5

Paste & test

Back in Settings: paste the Gist ID and token, then click Test Connection. If it passes, click Sync Now. Done.

💡 Privacy tip: A "secret" gist isn't listed in search, but anyone with the URL can read it. Don't put passwords or secrets inside your works.
